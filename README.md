# Deep Learning Image Classification (ResNet18)

Image classification project using transfer learning with a pretrained ResNet18 model on 20 classes from the DTD dataset.

## Details
- Framework: PyTorch
- Input size: 224x224
- Optimizer: Adam (lr=1e-4)
- Regularization: Dropout, Weight Decay, Mixup
- Data Augmentation: Random crop, flip, color jitter, rotation

## Results
- Training Accuracy: ~96%
- Validation Accuracy: ~85%

## Skills Demonstrated
- Transfer learning
- Data augmentation & regularization
- Overfitting reduction
- Model fine-tuning in PyTorch
